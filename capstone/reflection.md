## 1. How did your workflow change during this course? Give one concrete before/after example.
### Before this course, my workflow was very by the book and not flexible. I would start a project by outlining all the steps I thought were necessary, and then I would follow that outline strictly, usually not leaving much room for interesting/necessary insights since I would do exactly as asked, not much more and definitely nothing less.
### After taking this course, I adopted a more iterative and flexible approach. For example, when working on a recent project, instead of sticking to the outline or rubric to a tee, I still wrote my ideas, but allowed for refinement and suggestions from copilot chat to not only increase my output, but to improve what I do make.

## 2. What could the AI tools NOT do well? Give a specific example where Copilot or a skill failed you and what you had to fix manually.
### While Copilot is a powerful tool, it sometimes struggles with context-specific tasks. For instance, when I was working with data to check goodness of fit for a Poisson distribution, so I asked copilot to create code for GOF. It used chi-squared for GOF which did not work since my observation countss were too high, resulting in the degrees of freedom being inaccurate as well as the p-values being unreliable. I had to feed much more information to copilot in order to get a function that somewhat worked, then having to fix it up a bit still afterwards myself.

## 3. Which single skill or agent feature had the biggest impact on your work, and why?
### The feature that has had the biggest impact on my wok has been being able to ask copilot questions about my "library" or bibliography. I have a large number of references and being able to ask copilot to summarize or find specific information from them has saved me a lot of time and effort.

## 4. What would you build or automate next, now that you know how to create skills?
### Now that I know how to create skills, I would like to build a skill that automates the process of data cleaning and preprocessing for my datasets. This would include tasks such as handling missing values, normalizing data, and encoding categorical variables. By automating these repetitive tasks, I can focus more on the analysis and interpretation of the data rather than spending time on manual preprocessing. I just need to be careful that copilot fully understands what I am trying to do, and that it is able to handle the specific nuances of my datasets.
