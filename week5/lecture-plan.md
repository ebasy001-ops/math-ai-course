
# Lecture Plan
## Topic
The Fundamental Theorem of Calculus

## Audience
Undergraduate Calculus I

## Learning Objectives
By the end of this lecture students should be able to:

- Explain how differentiation and integration are related.
- State both parts of the Fundamental Theorem of Calculus.
- Compute definite integrals using antiderivatives.
- Interpret definite integrals as accumulated change.
- Apply the theorem to solve basic problems.

## Key Points

1. Review definite integrals as area under a curve.
2. Define accumulation functions.
3. Introduce FTC Part I.
4. Introduce FTC Part II.
5. Work through several examples.
6. Discuss real-world applications.
7. Summarize the relationship between derivatives and integrals.
